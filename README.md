# 🥷 つるふぇったの手裏剣修行  
**Tsurufetta's Shuriken Training**

忍者になって手裏剣を投げるアクションゲームです。  
的の中央を狙って手裏剣を投げ、アイテムを集めながら氷爆弾を撃ち落とそう！

## プレイ方法

1. スタート画面で段位を選ぶ（最初は初段のみ）
2. 左右ボタンで照準を合わせて「手裏剣！」をタップ
3. 的の中央に当てるとアイテムGET
4. 氷爆弾は手裏剣で撃ち落とす（落とせないと毒で10秒間撃てなくなる）
5. 段位をクリアすると次の段が解放される

## 段位と解放条件

| 段位 | クリア条件 | 解放 |
|------|------------|------|
| 初段 | 中央ヒット 5回 | 最初から遊べる |
| 中段 | 中央ヒット 8回 | 初段クリアで解放 |
| 上段 | 中央ヒット 12回 | 中段クリアで解放 |

## アイテム

| 色 | アイテム | 効果 |
|----|----------|------|
| 青 | 👑 水の王冠 | 次の投擲が二刀流 |
| 緑 | 🍵 お茶 | 飲むと「ありがと！」 |
| 赤 | 🧊 氷爆弾 | 敵の攻撃を消し飛ばす |
| 黄 | 🌸 花 | 手裏剣が増える＋ボイス |

## 氷爆弾とGAME OVER

- 撃ち落とせなかった氷爆弾に当たると毒（10秒間投擲不可）＋所持手裏剣減少
- ヒット回数が上限に達するとGAME OVER
  - 初段：10回 / 中段：8回 / 上段：6回
- GAME OVER時はロボつるんが出現し、「まだまだ修行が足りないね。特訓するよ。」が流れてスタート画面に戻る
